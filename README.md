# KosmAI

Sito statico di KosmAI: **la catena contro il lettore solo**. Generazioni di agenti AI trovano una legge nascosta
che un lettore solo, con lo stesso budget di chiamate, non trova. Esperimento pre-registrato (semi 331-336, Sonnet 5.5).

Questo repo contiene solo il sito pubblicato. La fonte, l'esportatore, il validatore e i risultati grezzi stanno in
`thenexus-vault/02_PROJECTS/cultural-ratchet/kosmai/`, dove una CI rigenera i dati dai risultati e li valida
prima di ogni copia qui.

Ogni elemento della pagina corrisponde a un campo dei file in `dati/` (formato `kosmai-log/1`, schema in `schema/`).
